# Kaspersky deck style system for web variants

Source: all eight supplied PNG slides in `Kaspersky (2).zip`, reviewed individually on 2026-08-30. This file translates the print language into responsive web constraints; it does not reproduce the A4 geometry.

## Non-negotiable visual DNA

- 60–75% of the experience stays calm and dark: matte charcoal `#14161B`, ink navy `#161B26`, deep teal `#152B30` / `#102C2C`.
- Primary accents are Kaspersky emerald and mint: `#0C8877`, `#1D9F8D`, `#42B899`, `#B0E7DD`, `#D4F0EA`.
- Light editorial surfaces use `#F3F7F6`; pure white is reserved for type and crisp highlights.
- Violet is optical support only: `#633391`, `#8C75C9`, `#A294C4`. No red, orange, yellow, cobalt or rainbow cyberpunk.
- Typography is local Kaspersky Sans Display. Headlines are oversized, regular-weight, tightly tracked and given generous line-height/clear space. Body text never competes with the visual.
- Hero visuals are simple object metaphors: 2–4 major graphite/glass forms, emerald edge light, at most one violet signal. No noisy diagrams, generic AI brains, locks, shields, code rain or decorative pseudo-data.
- Materials: graphite housings, dark glass, transparent acrylic, matte metal, soft reflections, controlled glow. Objects are integrated into the page and may crop beyond the viewport.
- Light pages remain part of the same system through pale mint backgrounds, black type, emerald surfaces and the same material language.

## Variation policy

The five new concepts may change page architecture, navigation and interaction model, but not the visual identity:

1. Spatial Command — real 3D decision gates / Babylon.js.
2. Kinetic Dossier — motion-first 90-day instrument / Lottie.
3. Risk Physics Lab — draggable weighted tokens / Matter.js.
4. Decision Graph — connected shift navigation / Cytoscape.js.
5. Kinetic Poster — fullscreen type scenes / Konva.

All variants use the exact landing-page content in `docs/content-map.md`.
